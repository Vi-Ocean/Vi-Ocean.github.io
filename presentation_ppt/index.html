Paper 01

MATHEMETRIC

Math Blind

Current MLLMs suffer from "Blind Faith in Text". They rely on textual shortcuts and fail to truly perceive geometric diagrams.

We hypothesize that low-level diagram perception is the bottleneck for high-level mathematical reasoning.

Paper 02

SymVAE

Symbolic vs. Pixel

Diagrams are sparse and symbolic. Pixel-based learners waste capacity on texture and color.

We propose a Symbolic Vision Learner that parses diagrams into primitives and logic rules.

SymVAE Framework

The first symbolic visual auto-encoder with graph topologies embedded in its latent space.

Hierarchical Process Reward Modeling in RL enforces step-level constraints:

Point → Line → Shape → Relations

Using a rendering engine as the decoder, the perceptual loss becomes a reward signal that drives gradient flow through reinforcement learning.

Performance

Reduction in MSE for geometric reconstruction.

+13%

Improvement on diagram understanding.

Gains on math reasoning.

✓

Cross-domain generalization to circuits and chemical structures.

Paper 03

Artemis

The Motivation

Current perception-policy models rely on free-form linguistic reasoning, resulting in poor localization and overfitting—one model per perception task.

In contrast, human perception uses coordinated spatial attention, rapidly localizing task-relevant objects before reasoning begins.

We propose Structured Visual Reasoning: a computational analogue of this "moving spotlight," where label–bounding-box pairs provide precise spatial localization and encode object identity.

Artemis Methodology

Structured Visual Reasoning for Policy Learning

Structured Reasoning

Intermediate steps as (label, bounding-box) pairs.

Unified Framework

RL-based perception-policy learning with visual rewards.

Cross-Task

Generalizes from grounding to counting & from natural Images to diagrams.

Paper 04

ViLoMem

Agentic Memory

Standard agents repeat mistakes because they lack integrated semantic memory.

ViLoMem mimics human cognition with Dual-Stream Memory (Visual + Logical) to grow and refine knowledge over time.

Grow-and-Refine Framework

Closed-Loop Memory Cycle

Memory Cycle

  • • Closed-loop learning mechanism
  • • Dual-stream retrieval (visual + logical)
  • • Verifier-guided trajectory filtering

Memory Generation

  • • LLM for logical error analysis
  • • MLLM for visual error analysis
  • • Similarity-based merge & create

Memory Retrieval

  • • Visual: Image-embedding + question filtering
  • • Logical: Problem analysis + text-embedding
