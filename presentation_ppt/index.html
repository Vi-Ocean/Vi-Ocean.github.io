"Signals vs. Symbols"

Natural Images

Images are natural collections of signals, semantically rich and suited for pattern recognition.

Math Diagrams

Diagrams are manual collections of symbols that encode abstract concepts, requiring precise topological understanding.

MLLMs exhibit flawed reasoning and hallucinations when processing diagram inputs, and we manually inspect the reasoning steps where visual perception errors escalate into larger failures.

Current reasoning test suites judge only the final answer, mixing perception with reasoning. Most research overlooks perceptual ability and instead attributes errors to reasoning alone.

We aim to uncover the perception weakness. The intuition is that a reliable perceptual foundation is essential for supporting downstream reasoning.

Hallucinations

Hallucinations arise when the model fails to understand the visual input, causing the LLM to infer or invent details that don't match what is actually present.

MATHEMETRIC Tasks

MATHEMETRIC isolates perceptual skills from high-level reasoning and features four tasks: shape classification, object counting, relationship identification, and object grounding, covering plane geometry, solid geometry, and graph representations.

Key Findings

  • 01

    Systematic evaluation of 20+ MLLMs shows poor performance on basic perceptual tasks (<45% accuracy), with near-zero accuracy on fine-grained grounding.

  • 02

    We propose structure-aware geometric captions—encoding shapes, attributes, relations, and precise bounding boxes—to train our 7B and 32B models.

  • 03

    Stronger perceptual ability leads to better reasoning performance, even without any explicit transfer mechanisms.

Improved perception stabilizes multi-step reasoning chains

Paper 02

SymVAE

Symbolic vs. Pixel

Diagrams are sparse and symbolic. Pixel-based learners waste capacity on texture and color.

We propose a Symbolic Vision Learner that parses diagrams into primitives and logic rules.

SymVAE Framework

The first symbolic visual auto-encoder with graph topologies embedded in its latent space.

Hierarchical Process Reward Modeling in RL enforces step-level constraints:

Point → Line → Shape → Relations

Using a rendering engine as the decoder, the perceptual loss becomes a reward signal that drives gradient flow through reinforcement learning.

Paper 03

Artemis

The Motivation

Current perception-policy models rely on free-form linguistic reasoning, resulting in poor localization and overfitting—one model per perception task.

In contrast, human perception uses coordinated spatial attention, rapidly localizing task-relevant objects before reasoning begins.

We propose Structured Visual Reasoning: a computational analogue of this "moving spotlight," where label–bounding-box pairs provide precise spatial localization and encode object identity.

Artemis Methodology

Structured Visual Reasoning for Policy Learning

Structured Reasoning

Intermediate steps as (label, bounding-box) pairs.

Unified Framework

RL-based perception-policy learning with visual rewards.

Cross-Task

Generalizes from grounding to counting & from natural Images to diagrams.

Paper 04

ViLoMem

Agentic Memory

Standard agents repeat mistakes because they lack integrated semantic memory.

ViLoMem mimics human cognition with Dual-Stream Memory (Visual + Logical) to grow and refine knowledge over time.

Grow-and-Refine Framework

Closed-Loop Memory Cycle

Memory Cycle

  • • Closed-loop learning mechanism
  • • Dual-stream retrieval (visual + logical)
  • • Verifier-guided trajectory filtering

Memory Generation

  • • LLM for logical error analysis
  • • MLLM for visual error analysis
  • • Similarity-based merge & create

Memory Retrieval

  • • Visual: Image-embedding + question filtering
  • • Logical: Problem analysis + text-embedding
