Hierarchical Process Rewards · SymHPR

A logic form decomposes into points → lines → shapes → relations. Our key idea: make the reward respect this hierarchy.

Point → Line → Shape → Relations

Errors propagate downward

If a point is wrong, any line built on it is meaningless — reward for line / shape / relation is reduced.

Flat-average rewards fail

Averaging six reward terms independently ignores compositional structure — policy stays near cold-start, no exploration.

Dependency blending

r'c = rc · [(1 − α) + α · r'p],  with α = 0.9.

Parent reward gates child credit — lower-level errors cannot be masked by superficial matches.

SymVAE · Framework

SymHPR encoder → rendering engine → visual reward closes the loop via GRPO.

ENCODER

SymHPR

A VLM refined via hierarchical process rewards — parses a diagram into a structured logic form (points, lines, shapes, relations).

DECODER

Rendering Engine

A deterministic data engine (not a neural net) that renders logic forms back into diagrams.

TRAINING

GRPO + Visual Reward

Final SymVAE trained via RL — visual reward from the rendered reconstruction. The engine is non-differentiable, so we use scalar rewards.

Making RL actually work on sparse diagrams

Vanilla GRPO collapses — diagrams are too sparse for stable reward signals.

THE PROBLEM

Reward variance collapse

Uniform backgrounds + thin lines → every rollout looks "good enough". Advantages shrink to zero, KL stays flat, policy stops exploring.

TWO FIXES

Hard negative contrastive

Inject Gaussian noise → fabricate hard negatives → restore reward variance.

Power-normalization annealing

r' = rα, α > 1 → amplify good / bad difference while preserving ranking.

Curriculum: aggressive exploration early (high noise, large α) → stable exploitation late (σ → 0, α → 1). Steady reward growth, healthy KL — and the encoder actually learns.

BEYOND THE NUMBERS

Two emergent properties

Cross-domain generalization

Primitives learned on plane geometry transfer to electric circuits and chemical structures — without domain-specific retraining.

Cross-lingual translation

Logic forms auto-translate into fluent CoT — following our point → line → shape hierarchy. Qwen2.5-VL-7B starts from global shapes, diverging from this structure.
